# 🐉 Save the Dragonfly

A simple and fun Pygame project where you help a dragonfly escape dangers and stay alive!

## 📦 Download

You can download the latest Windows executable from **[here](https://github.com/Rk-Virus/Save-the-dragonfly/releases/download/v1.0.0/game.exe)** section.

## 🎮 Gameplay

Control the dragonfly and avoid enemies approaching from all directions. The game tests your reflexes and timing. Try to survive as long as possible and beat your own high score!

### Controls

- `W` / `↑` - Move Up
- `S` / `↓` - Move Down
- `A` / `←` - Move Left
- `D` / `→` - Move Right

Click the **Play** button to start the game.

## 🛠️ Built With

- Python 🐍
- Pygame 🎮

## 🚀 How to Run

1. **Install Python** (if not already installed)
   👉 [Download Python](https://www.python.org/downloads/)

2. **Install Pygame**
   Open your terminal or command prompt and run:

   ```bash
   pip install pygame

3. **Run the Game**
   ```bash
   python main.py
   ```
